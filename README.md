# ReviewBoost AI - Smart Google Review Scanner & Local SEO Automation Suite 🚀

> Instant 1-Click Business Onboarding, High-Ranking Local SEO Keyword Extraction, Printable QR Standee Studio, and 1-Tap 5★ Google Review Writing Automation.

---

## 🌟 Key Features

1. **⚡ 1-Click Business Onboarding:**
   - Just paste a **Google Maps link** or enter the **Business Name**.
   - AI automatically resolves the URL, detects the business category, extracts top services, and identifies the city/area.

2. **🎯 Local SEO Keywords Intelligence Hub:**
   - Automatically generates **20+ High-Intent Local SEO Keywords** categorized into:
     - 📍 *Google Maps 3-Pack Ranking Keywords*
     - 🎯 *High-Converting Service Queries*
     - ⭐ *5-Star Reputation & Trust Signals*
     - 🚀 *Long-Tail Local Search Queries*
   - Interactive 1-click select/deselect and custom keyword addition.

3. **🖨️ Printable Acrylic QR Standee Studio:**
   - Multiple modern table/counter standee templates (*Acrylic Modern, Luxury Dark, Gold VIP, Clean Minimal*).
   - High-resolution PNG export & direct print mode.

4. **📱 1-Tap Zero-Friction Customer Review Landing Page:**
   - Mobile-optimized landing page with business branding and 5.0 rating score.
   - Pre-fills a ready-to-post 5-star review enriched with the business's target SEO keywords.
   - Single tap on **"⭐ Post 5★ Review on Google"** copies review text to clipboard, triggers celebration confetti, and immediately opens the Google Review writing modal!

---

## 🛠️ Tech Stack

- **Frontend:** React 19, Vite, Lucide Icons, Canvas Confetti, HTML2Canvas, QRCode.react.
- **Backend:** Node.js, Express REST API, LowDB / Persistent JSON storage.
- **AI & NLP Engine:** Smart Semantic Keyword Blender & Review Synthesizer (+ optional Google Gemini API key support).

---

## 🚀 Getting Started Locally

### 1. Install Dependencies
```bash
npm install
```

### 2. Run in Development Mode
```bash
npm run dev
```
- **Frontend:** `http://localhost:5173`
- **Backend API:** `http://localhost:5000`

### 3. Build for Production
```bash
npm run build
```

---

## 🌐 Deploying to Vercel / Render / Netlify

1. Push this repository to GitHub.
2. Connect your GitHub repository to **Vercel** or **Render**.
3. Set build command: `npm run build` and output directory: `dist`.
4. Your live public review scanner will be available 24/7 globally!
